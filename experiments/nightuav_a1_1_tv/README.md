# NightUAV-A1-1：普通TV受控实验

## 协议与完成状态

A0结构保持不变；随机初始化seed=1149；冻结U3D v2.1 train；256×256、batch=2；Adam lr=0.001、weight_decay=0。仅使用 L_rec=mean(abs(I*R-X)) 与用户定义的水平、垂直绝对差均值之和 L_tv。完成200次尝试、200次有效参数更新，无异常，无延长预算、dev调参或A2训练。

复用A1-0保存的采样计划，并逐批核对实际图像与crop记录，全部一致。相同源码和seed的初始化重放参数完全一致；初始固定训练批次MAE及两张历史初始dev浮点预测完全一致。A1-0没有保存初始参数快照，因此没有声称直接与历史初始checkpoint逐参数比较。最终checkpoint重新加载完全一致，受保护历史文件哈希未改变。

## TV权重依据

训练前固定取前8个train批次，计算初始重建及TV的参数梯度范数RMS；不执行更新，不使用dev选择权重。预设加权TV初始梯度RMS为重建的10%。

- 重建梯度RMS：0.14859014927335767；TV梯度RMS：0.017171479160034444。
- lambda_tv = 0.1 × 0.14859014927335767 / 0.017171479160034444 = **0.8653310986696595**。
- 初始损失均值：重建0.1977537964，TV 0.0009465260。

10%是本次探索性干预强度预设，不是最优值，也不保证训练后期梯度比例恒定。只执行这一组权重。

## 科研解释与下一步

普通TV使I的TV降低约50%，同时降低I/R梯度幅值重叠，但两张dev重建MAE均上升，R的上边界邻近比例增加。证据支持“TV改变分量分配、降低光照纹理”，不足以支持“分解质量或物理正确性已经改善”。未观察到全图近似常量I，仍不能排除局部结构混叠及尺度分配歧义。仅两张dev、单seed与短程预算限制了外推。

可以开始非配对日间反射约束的理论与数据适用性研究，但本结果不足以支持立即加入对齐损失开展A2训练。应先明确日夜场景构成、材料与相机处理差异，以及如何避免分布对齐抹除真实反射差异；无反射真值和成像标定，不能默认跨场景反射分布相同。本次停止于A1-1。
