# NightUAV-A2-1：固定日间弱结构先验受控实验

2026-10-29。一次固定配置实验已完成200次尝试、200次有效更新，无NaN/Inf或异常；未延长预算、未调参、未启动A3。仅新增训练入口 scripts/train_nightuav_a2_1_structural_prior.py 与本独立实验目录。

## 配置、参照与数值检查

A0保持10276参数。seed=1149，原生4K图像256×256 crop，夜间batch=2，FP32，Adam lr=0.001、betas=(0.9,0.999)、eps=1e-8、weight_decay=0，无调度/裁剪。初始化参数哈希、初始dev浮点预测及全部200批实际夜间采样/crop与A1-1完全一致；不是从最终checkpoint续训。最终checkpoint重新加载匹配，受保护历史文件哈希未变。

TV保留历史完整精度0.8653310986696595，提示中的0.8653311视为显示舍入。A2-0建议的Cnight没有在本次执行，符合本轮仅一次日间参照训练的授权；不能据此识别日间来源相对一般结构约束的独有收益。

日间参照：从light/train的800张按完整路径排序，独立Random(1149)打乱后固定400张，每张一个原生256 crop；坐标和全黑同图重试使用独立seed1149流，最多50次重试，不与夜间按编号配对。不使用dev/test构造参照。完整路径、SHA256、crop和逐图统计保存于day_reference.json。日间图像不经过模型、不参与重建优化；仅固定数据统计作为目标。选定日间文件与夜间dev未发现相同文件字节，不能排除近重复或同场景，结果仅是开发集探索。

定义：Y(A)=0.2126 A_R+0.7152 A_G+0.0722 A_B；q=tanh(|Δlog(Y(A)+1/255)|)，水平/垂直相邻1像素。有效边要求原始输入两端亮度在[0.05,0.95]且maxRGB<0.99。掩码不依赖R。每图先对有效边求mean(q)、mean(q²)，再按有效图等权平均；二阶项不是方差。空分量不参与均值与距离。四维目标为：

`[0.08480584621429443, 0.02655879594385624, 0.08639145642518997, 0.027240857481956482]`

分量顺序为水平一阶、水平二阶、垂直一阶、垂直二阶。400张日间crop全部对四分量有效。目标detach且不含可训练参数，运行全过程逐步确认未改变。L_struct为夜间batch等图权矩与此目标的四分量平均平方距离。

训练前固定前8个配对train批次，无参数更新：基础目标梯度范数RMS=0.148819178242，结构梯度范数RMS=0.00293604665807。固定lambda_struct=0.1×前者/后者=**5.06869255067**。10%是初始干预强度，不是最优值或后期梯度比例保证。

本轮损失小张量公式/空掩码/反向检查通过；真实前8批损失有限，结构梯度到达R头和编码器，无I头直接梯度。校准要求每批四分量有效且两组梯度范数>1e-12，避免零梯度除法；并非统计覆盖充分性证明。未重复A0整体验证。

第159批（0378、0115）两个crop均无有效结构边：按A2-0规则L_struct=0，仍执行重建+TV更新；不替换样本、不延长。本次200次总更新不等于200次都有结构梯度。

## 风险与科研解释

|图像|亮区重建MAE，前→后|全图R亮度绝对Laplacian，前→后|输入平坦区同指标，前→后|
|---|---:|---:|---:|
|0049|0.120981 → 0.137529|0.027899 → 0.075090|0.007568 → 0.009622|
|0179|0.106994 → 0.130778|0.019531 → 0.050201|0.004806 → 0.007503|

亮区由固定输入Y>0.7定义。高频代理是四邻域亮度Laplacian绝对均值；平坦区由输入中心与四邻居差均<0.01固定，去掉外边框。该代理未用于损失、挑选checkpoint或调参，包含真实纹理、边缘及噪声影响，不能直接叫噪声量。两图全局高频代理约增至2.6–2.7倍，输入平坦区域也分别增加约27%和56%，存在过度高频匹配风险。

已查看两张最终四列缩略显示，并对照0049的A1-1结果。I/R中仍可见场景结构，不能凭外观宣布解耦；缩略图不能排除像素级噪声，需负责人查看原尺寸。未新增自动美化、逐图归一化或额外曝光处理。

证据分开解释：①结构项可优化；②固定train及两dev的R统计更接近指定目标；③真实物理意义未获证明。全图MAE改善掩盖了亮区MAE恶化，R边界与高频代理上升使“保持重建并避免退化”的完整假设尚未得到支持。训练之前没有批准数值质量容忍线，故不在看到结果后补设通过阈值。

建议：值得保留为后续受控机制研究的候选，但当前不足以直接推进正式A3或扩大三损失训练。先人工审核高频、亮区与颜色变化，再决定是否批准来源对照；本轮不执行Cnight、不改权重、不启动后续实验。不能声称日间参照优于一般结构正则、泛化改善或真实反射恢复。
