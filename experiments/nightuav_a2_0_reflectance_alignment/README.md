# NightUAV-A2-0：非配对日间反射约束可行性研究

日期：2026-10-29。状态：研究提案，未实现损失、未加载模型推理、未训练。仅新增本报告；A0、A1历史结果和冻结划分均未修改。

## 1. 结论与证据层级

**实测事实：** 日间训练图像可访问，数量与尺寸适合现有轻量框架；但日夜场景可比性与交叉关系尚未建立。数据支持探索性非配对约束研究，不支持直接将日间RGB当作反射真值。

**理论判断：** 普通重建、TV与边际分布接近不能保证可辨识分解。最适合首先证伪的是方案C的“固定日间局部对数亮度梯度低阶统计”，不优先采用可同时漂移的双域预测R对齐。该统计仍包含日间光照、内容、噪声及ISP影响，只是弱结构先验候选，不是反射监督。

**待检验假设：** 在相同初始化、夜间样本/crop与预算下，弱结构统计约束能比TV单独使用更好地保留R的空间变化，且不进一步明显恶化重建、制造边缘或推高边界饱和。损失下降本身不算支持证据；本轮没有验证此假设。

## 3. 三种候选比较

| 方案 | 对齐对象/最小成本 | Retinex解释与局限 | 退化与必要验证 |
|---|---|---|---|
| A：RGB通道统计 | R_n与X_d的RGB均值/方差；无额外网络；可微，成本最低 | 日间X_d仍等于受光照和相机处理影响的观测；均值还混合材质/场景比例；没有理由假设I_d=1 | 可改变色偏/整体尺度、以I补偿R；均值约束容许常量R，均值方差也容许无关纹理。必须观察颜色、重建、边界和内容；不建议首轮 |
| B：双域预测R | 共享A0分别得到R_n、R_d；均值/方差距离或其他可微距离；需日间前向，若两端更新还需日间重建/平滑；共享参数不增加数量，但增加计算 | 比把RGB当真值更统一，却只是两个有偏预测的匹配；不同材质组成仍改变R分布；独立两网还增加自由度 | 两端可一起漂移/坍缩；日间stop-gradient只截断当前梯度，下步共享参数仍会改变目标。固定教师能消除目标漂移，但现有夜间A1模型不是已验证的日间反射教师。必须增加“日夜重建+TV但无对齐”对照以隔离额外数据效果 |
| C：局部弱光照敏感统计 | R_n与固定X_d的局部对数亮度梯度统计；不逐像素匹配，不比较RGB均值；无需新增网络，几次差分与归约 | 在局部光照缓变、非零非饱和且近似乘性时，log梯度较弱依赖光照；并非完全不变，阴影边界/噪声/ISP和场景尺度仍影响 | 低阶矩丢失位置语义，可能用噪声或错误边缘匹配；缩放歧义仍在。必须结合重建、原位置结构、人审及退化统计；作为最小可证伪候选优先 |

[Retinex-Net](https://arxiv.org/abs/1808.04560)使用配对低/正常光图像的反射一致性与光照平滑；其配对一致性依据不能直接转为“不同场景边际反射分布相同”。本报告的候选公式是工程提案，未声称为该论文方法或原创创新。

## 4. 推荐C的最小数学定义（尚待批准）

仍用A0：f_theta(X_n)=(I_n,R_n)，I∈[0,1]^(N×1×H×W)，R∈[0,1]^(N×3×H×W)，X_hat=I_n R_n。编码RGB模型不等于完整物理成像。

定义luma(A)=0.2126A_R+0.7152A_G+0.0722A_B。对方向a∈{水平,垂直}的相邻像素(p,p+a)：

    q_a(A,p) = tanh(abs(log(luma(A,p+a)+eps)-log(luma(A,p)+eps)))
    eps = 1/255

eps为数值稳定候选常量，tanh使极端梯度贡献有界；不代表量化单位下的真实噪声方差。固定尺度是原生4K图上的1像素差分，不改用不同分辨率估计训练目标。

固定掩码只由该图原始输入X计算：像素有效当0.05≤luma(X)≤0.95且max_c X_c<0.99；邻边两端均有效才纳入。夜间R的掩码由X_n产生，日间参考掩码由X_d产生，均不依赖可训练输出，不能通过改变预测掩码逃避损失。这些阈值仅为待批准的固定信噪/饱和排除规则，不是已优化值；会偏向夜间较亮可见区域，不能宣称约束了全部暗区。

每张图、每个方向取有效边q的一阶矩m_a,1与二阶原始矩m_a,2（q²均值），组成4维phi(A;X)。先逐图计算，再对图像等权平均，避免纹理多/有效像素多的图主导。若某方向无有效边，该方向记为无效并报告，不把空均值设成零目标；训练批次该方向全部无效时不产生该方向对齐项，保留夜间重建更新并记录覆盖。若参考某方向没有有效样本，或初始训练校准批次无有效对齐梯度，停止候选准备并报告，不临时改阈值。

日间目标来自事先固定的日间train crop计划，不经过分解器：

    t_d = average_over_day_crops phi(X_d;X_d)
    L_align = mean_valid_components((average_over_night_batch phi(R_n;X_n) - stopgrad(t_d))²)
    L_A2 = L_rec,n + 0.8653310986696595 * TV(I_n) + gamma * L_align

无效分量按各分量有效图数归一化，所有分量均无效时L_align贡献为0并记录。gamma尚未确定，本轮不计算或训练。未来拟按固定前8个train批次、全部参数向量上对齐梯度与基础目标梯度RMS比例10%一次性确定；不得利用dev调权。比例是探索强度约定，不是最优权重；若梯度近零/非有限，停止而非令gamma异常放大。批准前需明确最小有效覆盖与可接受重建退化界限。

**梯度路径：** L_align→R头→共享编码器；对I头没有直接梯度，但编码器改变可间接改变I。重建更新两头与编码器，TV更新I头与编码器。日间目标是数据常量，无日间网络分支更新、无教师伪真值、无像素对应损失。训练时只需夜间模型输入；日间crop可预先计算4维目标，无需同时保留日夜模型激活，8GB下新增内存开销预期很小，尚未运行测量。

**理论近似：** 理想标量乘性模型有log Y(X)=log I+log Y(R)，所以当局部log I变化较小时，观测梯度近似反射梯度。eps、编码RGB、阴影、彩色灯和相机非线性均破坏严格等式。只比较统计进一步要求内容/材质/目标尺度组成大致可比；本地数据尚未证明此前提。因此此项只能用于测试弱结构先验，不能标为可靠反射分布一致性监督。

## 5. 不可忽略的退化

- 对任意保持范围合法的正函数a，I'=aI、R'=R/a可保持重建；分布统计无法确定物理尺度。局部对数梯度又近似忽略常量缩放，无法解决该歧义。
- I≈1、R≈X可同时重建好且TV小；本方案不保证排除。非零参考梯度使完全常量R通常有非零对齐损失，但绝对差在零点的实现梯度可能为0，不能声称防坍缩保证。
- 单通道I下，空间常量RGB R不能精确表示所有有色纹理输入，但可牺牲重建，把大量强度结构转移到I。二阶矩能限制部分低方差退化，不能阻止空间重排、伪边缘或高频噪声。
- 方案B若两端更新，即使共享网络，也可能利用输入域差异学习两种有偏分配，使两端统计一起靠拢。低距离只说明预测相似；stop-gradient并不等于跨步冻结。加入两域重建也不能完全解决乘性尺度与材质混杂。
- C没有移动目标问题，但把日间阴影、植被、密集建筑统计迁移到不同夜间内容仍可能错误。只做亮度梯度不会约束色偏；不以本轮增加颜色损失补洞。

## 6. A2-1最小受控协议（仅设计）

### 训练边界与对照

保持A0结构、seed1149随机初始化、Adam lr0.001/weight_decay0、256crop、夜间batch2与200次有效更新；不从A1-1最终checkpoint续训。复用A1-0/A1-1夜间采样及实际crop计划，核对初始化与初始预测，保留相同空黑crop协议。开发0049/0179仅初始/最终评价，不参与选参。

| 条件 | 目标 | 作用 |
|---|---|---|
| 历史A1-0 | 夜间重建 | 已有背景基线，不重跑 |
| C0：A1-1基线 | 夜间重建+固定TV | 初始化、采样等逐项可确认一致时复用历史结果；如不能确认，报告不能严格配对，不自动重跑 |
| Cday：候选 | C0+gamma*距离到t_d | 首要检验日间弱结构统计约束 |
| Cnight：必要来源对照 | C0+同一gamma*距离到固定夜间输入统计t_n | 区分日间参考与一般结构矩约束的贡献；t_n来自同一冻结train计划，不用dev，不再单独调gamma |

建议只新增Cday和Cnight两个固定200步条件；这不是多个权重搜索。若仅批准Cday，可只说明新增约束的总体影响，不能归因于日间数据特有价值。同gamma仍不保证两目标实际梯度强度相同，应记录两者的初始及过程梯度量级，不能把差异全归于日间语义。

### 日间采样与数据混杂

日间按完整路径排序，从现有800 train中用独立seed1149 RNG打乱，固定400个图像crop，对应200步×2个夜间样本的参考预算；crop为原生4K的256×256随机坐标，独立于夜间RNG，不按编号配对、不按相似性挑样本。记录完整路径/哈希/crop；全黑重采样只在同图、固定重试上限内进行。先固定计划，再计算等图权目标t_d；Cnight用历史夜间400个crop统计t_n。禁止因目标距离或dev表现重新选图。400个crop只是参考预算，并非日间独立场景数。

Cday/Cnight都只有夜间重建与TV；没有额外日间重建优化、没有额外更新次数、没有新增模型参数。因此可隔离“多训练日间样本带来额外优化”的混杂。C0不使用目标，Cnight控制一般结构正则效果；三者夜间样本和更新预算一致。固定目标统计计算成本另行报告。

日间train与夜间dev的场景关系尚未审定。未来A2-1实施前须明确来源边界：复用已有证据检查选定日间参考与dev是否有已知交叉；如发现交叉，停止并提交单独的数据准入决定，不改变冻结夜间划分或自动替换日间样本。没有完整跨域场景审计时，结果只称固定开发集探索，不能称独立跨场景泛化。

### 验证与判定

训练前：仅对候选损失做小张量数值/梯度检查、有效掩码覆盖与训练初始梯度校准；冻结gamma、参考计划和配置。不得重复A0全套验证或运行权重搜索。

同时记录：固定train批次与两dev重建MAE及亮度分区误差；I/R均值、标准差、分位数、边界比例；I TV、R空间梯度、I/R梯度重叠；对齐距离和有效边覆盖；非有限值与有效更新数。与A1-1相同[0,1]→[0,255]四列图及相同位置细节人工审查，特别检查伪边缘、纹理丢失、噪声放大、颜色变化与I趋常量。720p评价与原生4K训练差分尺度不同，距离分别报告，不直接横比或据dev选择尺度。

证伪条件：仅对齐距离下降而重建/边界/细节更差，不支持假设；Cday无优于Cnight的可解释迹象，不支持日间来源的额外作用；I/R结构重叠下降但出现常量化或噪声匹配，同样不支持。重建退化容忍界限须在未来运行前由负责人确定，不能看结果后设阈值。单seed、两图和无反射GT最多支持行为判断，不能证明真实物理解耦。

遇到NaN/Inf、无有效梯度、数据边界不符或关键配对条件失败即停止；不改权重、不延长、不选best。保存独立实验结果。本报告不构成A2-1启动命令或训练授权。
