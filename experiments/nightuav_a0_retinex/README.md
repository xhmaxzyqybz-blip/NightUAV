# NightUAV A0 显式 Retinex 分解原型

状态：仅结构与数值检查；测试结果以 numeric_checks.json 为准。本轮无优化器、无参数更新、无数据集训练、无增强成果。

## 架构与申请书对应

已定向读取原 DI-Retinex mymodel.py、现有增强目录及桌面《项目内容.docx》分解方案段落。DI 前两层 3×3 卷积可作为轻量特征编码器结构参考，但现有六通道头是 c/b 系数，不是 I/R；B0 wrapper 也不是分解网络。

A0 新建独立模型：3→32 的3×3卷积/ReLU→32→32 的3×3卷积/ReLU→两个1×1头。光照头输出1通道，反射头输出3通道，均接 sigmoid。共10,276参数，理论感受野5×5，保持输入空间尺寸。相对原DI的64通道骨干缩小为32通道，仅为最小工程原型，不是经搜索选出的最优容量；复用其浅层卷积思路与现有PyTorch环境，不导入冻结DI模块、不继承E15权重，也不声称复现U3LIE编码器。

I=sigmoid(h_I(F(X)))，R=sigmoid(h_R(F(X)))，X_hat=I⊙R。X为N×3×H×W，I为N×1×H×W，R和X_hat为N×3×H×W；I沿RGB广播。输入契约为有限的[0,1]浮点编码RGB。本轮不做相机响应反演，乘性关系只是编码域的结构假设，不是校准后的辐射成像模型。

sigmoid理论输出(0,1)，浮点可能达到端点；乘积数值范围[0,1]。不做除法、对数或后续clamp，不引入不必要epsilon。大logit仍可能饱和并导致梯度消失，A0只验证初始状态。编码器Kaiming normal，两个头Xavier uniform gain=0.1，偏置全0；seed1149。初始I/R通常近0.5、乘积近0.25，不能解释为增强。

## 本轮检查范围

随机256×256输入、非方形批输入2×3×33×47、全黑/全白32×32；检查形状、范围、I/R广播乘积、L1重建公式、输出张量与两个头的有效有限梯度、随机输入下编码器梯度，以及参数未改变。另用I=.5、R=.4、X=.7的双精度标量例子检查解析重建梯度。全黑输入时某些权重梯度为零属预期，两个输出头的偏置仍有有效梯度。

只使用autograd.grad，不调用optimizer或step；不保存模型权重，不将随机图像导出为增强成果。RTX 5060 Laptop上的256 crop检查只能说明小输入可运行，不等于已验证4K整图训练、恢复训练或长期稳定性。

## A1 最小无监督分解训练建议 尚未批准

1. 重建：L_rec=mean(|I⊙R−X|)。它约束乘积保真，不要求正常光GT，也不驱动增强。必须先确定继续编码RGB，还是采用明确记录的逆响应近似；不能默认JPEG已经物理线性。真实噪声、镜面、自发光、饱和和ISP会破坏简单乘性假设。
2. 光照平滑：先比较L_rec与L_rec+λ_s L_TV两个最小目标。L_TV可定义为水平/垂直相邻I绝对差的各自均值之和，按有效边数归一化。λ_s必须在train约束下另行批准，不从dev反复选择。本轮未实现平滑损失。普通TV会平滑小灯和照明边缘，还可能偏好常量I；只有实验表明必要时再讨论结构加权，不同时堆叠多个机制。
3. 必须同时记录重建、I/R分布、I接近1/常量化、各分支梯度、纹理进入I及噪声进入R的现象；不能仅凭重建下降宣称解耦成功。同内容的可控合成曝光变化可作为后续反射稳定性检查，但不是伪正常光真值，也不能替代真实成像验证。

关键退化：I≈1、R≈X可重建，同时使TV≈0；所以重建加普通TV仍不能排除此解。在合法范围内，I'=sI、R'=R/s给出相同乘积，s可为空间函数，产生尺度与结构分配歧义。中性灰图还允许I携带几乎全部空间变化、R近常量；共享单通道I不自动获得照明含义。sigmoid只能逼近端点，但不能在科学上消除退化，还可能通过饱和抑制梯度。

如果A1出现这些退化，应停止物理解耦结论。尺度约定、照明锚或反射不变性等额外信息各有先验代价，需提出独立假设和消融后再批准；不在A0暗中添加。任何仅调整I的增强过程也需要另行定义，不由分解重建自动获得。

## A2 非配对日间反射分布对齐建议 尚未批准

申请书提出未配对日间反射统计对齐，但当前没有本轮核验过的日间训练清单、场景组成与数据边界。不得默认可直接使用，也不得将日间图像作为夜间同场景GT。

可供后续讨论的最小定义是共享分解器所得R夜/R日的固定特征φ分布距离，例如固定核MMD²(E_Rnight,E_Rday)。采用预先登记的特征与核，并同时维持两域重建；本轮不实现，不确定权重。仅RGB分布会忽视结构，反射网络也可能通过内容扭曲或常量化使距离降低。

理论依据仅是理想同一材质在照明改变下反射近似稳定，不能推出跨场景边际p(R)一致：p(R)=Σ_s p(R|s)p(s)，两域的场景/材质/目标尺度组成可能不同；光源光谱、视角、噪声和相机处理也不同。强行对齐可能抹去真实颜色和小目标。A2前需核验日间数据与场景混杂，保留无对齐对照，并检查内容保持。分布距离降低不是反射物理正确性的证据。
