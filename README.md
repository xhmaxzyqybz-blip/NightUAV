# NightUAV

当前阶段：**实验平台与 Baseline 建设**。

## 研究方向

- UAV Low-Light Enhancement
- Retinex
- Task-aware Enhancement
- Object Detection
- Cross-dataset Generalization

## 目录用途

| 目录 | 用途 |
| --- | --- |
| `code/U3D_Toolkit/` | 已下载的 U3LIE 官方仓库，保留原始内容 |
| `code/src/enhancement/` | 项目自研低光增强代码 |
| `code/src/detection/` | 目标检测相关代码 |
| `code/src/evaluation/` | 图像质量、检测与泛化评价代码 |
| `code/src/datasets/` | 数据加载与预处理代码 |
| `code/src/utils/` | 通用工具代码 |
| `datasets/U3D/` | 已下载的 U3D 数据，保留原始内容 |
| `experiments/` | 按统一编号组织的正式实验 |
| `results/figures/` | 汇总图表中的图片 |
| `results/tables/` | 汇总结果表格 |
| `results/demos/` | 演示结果 |
| `configs/` | 实验与方法配置 |
| `scripts/` | 数据处理和实验运行脚本 |
| `checkpoints/` | 模型权重与训练检查点 |
| `papers/core/` | 核心论文 |
| `papers/baselines/` | Baseline 论文 |
| `papers/surveys/` | 综述论文 |
| `docs/` | 项目计划、团队分工、会议记录、数据集报告、方法笔记和复现报告 |
| `.agents/` | 项目已有的智能体 Skill 配置 |

项目计划见 [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md)，实验编号规范见 [experiments/README.md](experiments/README.md)。
